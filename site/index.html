Each step pairs evidence with the student’s expectation. That makes a replay readable as reasoning, not just a wall of logs.

  1. 01

    Choose the evidence

    Paste one command and only the output that matters, or add named before/after file snapshots.

  2. 02

    Name the hypothesis

    Write what you expected before the run and what the result changed. Secrets are masked before saving.

  3. 03

    Export one local bundle

    Send a readable JSON file. Your tutor imports it, uses arrow keys to replay, and sees original snapshots.
